# 智能家居系统

基于 STM32 + ESP8266 + Flutter 的智能家居控制系统，支持手机 APP 远程控制灯光、传感器数据实时显示等功能。

## 系统架构

```
┌─────────────┐         WiFi          ┌─────────────┐         UART         ┌─────────────┐
│  Flutter APP │ ◄──────────────────► │   ESP8266    │ ◄──────────────────► │    STM32     │
│   (手机端)   │    TCP 协议           │  (WiFi模块)  │    AT 指令           │  (主控制器)  │
└─────────────┘                       └─────────────┘                      └─────────────┘
                                                                                │
                                                                    ┌───────────┼───────────┐
                                                                    │           │           │
                                                                ┌───┴───┐  ┌────┴────┐  ┌───┴───┐
                                                                │ DHT11 │  │  LED x3 │  │ 继电器 │
                                                                │温湿度 │  │  灯光   │  │  门锁  │
                                                                └───────┘  └─────────┘  └───────┘
```

## 功能特性

### 已完成功能 ✅
- **WiFi 通信**：ESP8266 AP 模式，手机直连
- **三路灯光控制**：客厅、卧室、厨房独立开关

## 接线说明

### ESP8266 接线
```
ESP-01S 3V3    → STM32 3.3V
ESP-01S GND    → STM32 GND
ESP-01S TXD    → PA10 (USART1_RX)
ESP-01S RXD    → PA9  (USART1_TX)
ESP-01S CH_PD  → 3.3V
```

### 传感器接线
```
DHT11 DATA     → PA0 (需4.7K上拉电阻)
HC-SR501 OUT   → PA1
VS1838B OUT    → PA2
蜂鸣器 I/O     → PA3
```

### LED 接线
```
客厅 LED       → PA4 (低电平点亮)
卧室 LED       → PA5 (低电平点亮)
厨房 LED       → PA6 (低电平点亮)
```

### 继电器接线
```
继电器 IN1     → PB0 (灯光)
继电器 IN2     → PB1 (空调)
继电器 IN3     → PB5 (门锁)
```

## 使用说明

### 1. 硬件准备
1. 按照接线说明连接所有模块
2. 确保 ESP8266 已烧录 AT 固件
3. 使用 ST-Link 烧录 STM32 固件

### 2. 烧录 STM32 固件
1. 用 Keil MDK 打开 `hardware/SmartHome.uvprojx`
2. 编译工程 (F7)
3. 下载到 STM32 (F8)

### 3. 安装 APP
1. 将 `makeapp/智能家居.apk` 复制到手机
2. 安装 APK（需允许安装未知来源应用）

### 4. 使用步骤
1. 手机连接 `SmartHome` WiFi（密码：12345678）
2. 打开 APP，点击"连接测试"
3. 等待显示"已连接"
4. 即可控制灯光和查看传感器数据

## 通信协议

### APP → STM32 命令格式
| 命令 | 功能 |
|------|------|
| `led_living_on` | 打开客厅灯 |
| `led_living_off` | 关闭客厅灯 |
| `led_bedroom_on` | 打开卧室灯 |
| `led_bedroom_off` | 关闭卧室灯 |
| `led_kitchen_on` | 打开厨房灯 |
| `led_kitchen_off` | 关闭厨房灯 |
| `led_all_on` | 打开所有灯 |
| `led_all_off` | 关闭所有灯 |

### STM32 → APP 数据格式
```
温度,湿度,PIR,客厅灯,卧室灯,厨房灯
例: 25,60,n,1,0,1
```

## 常见问题

### Q: APP 无法连接设备
A: 请检查：
- 手机是否连接到 `SmartHome` WiFi
- ESP8266 是否正常工作（AT 指令测试）
- WiFi 密码是否正确（默认：12345678）

### Q: 灯光控制无响应
A: 请检查：
- LED 接线是否正确（低电平点亮）
- GPIO 引脚是否配置正确
- 重新烧录固件

### Q: 传感器数据不更新
A: 请检查：
- DHT11 接线是否正确
- 是否需要上拉电阻（4.7K）
- 传感器是否损坏
