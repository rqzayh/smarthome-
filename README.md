# 智能家居系统

基于 STM32 + ESP8266 + Flutter 的智能家居控制系统，支持手机 APP 控制灯光、传感器数据实时显示等功能。

## 系统架构

```
┌─────────────┐         WiFi          ┌─────────────┐         UART         ┌─────────────┐
│  Flutter APP │ ◄──────────────────► │   ESP8266    │ ◄──────────────────► │    STM32     │
│   (手机端)   │    TCP 协议           │  (WiFi模块)  │    AT 指令           │  (主控制器)  │
└─────────────┘                       └─────────────┘                      └─────────────┘
                                                                                │
                                                                    ┌───────────┼───────────┐
                                                                    │           │           │
                                                                ┌───┴───┐  ┌────┴────┐  ┌───┴───┐
                                                                │ DHT11 │  │  LED x3 │  │ 继电器 │
                                                                │温湿度 │  │  灯光   │  │  门锁  │
                                                                └───────┘  └─────────┘  └───────┘
